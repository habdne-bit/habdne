Reading:
- h11 (the relay's HTTP protocol, through TLSExtensionH11Protocol) accepts a request target of
  bytes 0x21 to 0x7E only (h11/_abnf.py: request_target = vchar+, vchar = [\x21-\x7e]). Any
  other byte is refused by the server, 400, before the application is called.
- So meta.subscription's QUERY_NOT_UTF8 branch cannot be reached through this entry point: a
  query reaching it is ASCII, and decodes. It stays as a guard for any other server.
- The warning line uvicorn writes holds no request line, no query and no token.
